## 📌 Executive Summary

**ATLAS-Q** is an advanced meteorological intelligence and 0–60 minute high-resolution probabilistic thunderstorm nowcasting platform. 

Combining a **luxury editorial design aesthetic** with **functional atmospheric analytics**, ATLAS-Q bridges observational meteorology and actionable civil defense warnings across the Indian subcontinent.

The platform ingests and harmonizes multimodal observations across 5 domains:
1. **Doppler Weather Radars (DWR):** S-Band and C-Band volumetric reflectivity ($Z$), radial velocity ($V$), and echo tops.
2. **Geostationary Satellite:** INSAT-3D / INSAT-3DR Thermal Infrared (TIR) and 6.7µm Water Vapor channels.
3. **Lightning Location Networks (LLN):** IITM Pune / Damini cloud-to-ground (CG) and intra-cloud (IC) pulses.
4. **Surface Synoptic Observations:** Open-Meteo & IMD Automatic Weather Stations (AWS) reporting surface winds, temperature, pressure, and thermodynamic CAPE instability.
5. **Numerical Weather Prediction (NWP):** NCMRWF / IMD High-Resolution WRF (3km) environmental wind shear and moisture flux fields.

## 🏷️ Transparent Data Provenance Policy

Every metric and forecast displayed across ATLAS-Q is strictly tagged:
- **`REAL`**: Directly observed instrument telemetry (radar volumes, satellite TIR, lightning pulses, AWS).
- **`DERIVED`**: Values calculated from raw observations (centroids, area, echo tops, flash density).
- **`PREDICTED`**: Forecast outputs generated by kinematic advection models (0–60m trajectory vectors with horizontal uncertainty radii).
- **`SIMULATED`**: Synthetic, deterministic meteorological scenarios generated for technical evaluation and repeatable SIH viva demonstrations.

## 🏛️ Comprehensive 9-Page Architecture

1. **Overview:** Executive synoptic indicators, interactive vector GIS map, critical alerts, and selected storm telemetry.
2. **Live Radar:** Volumetric 2D reflectivity grid ($32 \times 32$) heatmap canvas with connected-component spatial clustering (8-connectivity) and adjustable dBZ threshold.
3. **Storm Tracking:** Consecutive observation centroid matching, velocity/heading calculation, and 0–60 minute extrapolation tables with expanding uncertainty cones.
4. **Lightning Intelligence:** Spatial strike density (per 1000 km²), Cloud-to-Ground (CG) vs Intra-Cloud (IC) balance, peak current ($kA$), and shelter safety recommendations.
5. **Risk Intelligence:** Multi-factor Bayesian Hazard Index ($0.35 \times \text{dBZ} + 0.30 \times \text{Lightning} + 0.20 \times \text{CAPE} + 0.15 \times \text{Shear}$) with radial probability gauge and explainable operational alerts.
6. **AI & Optimization:** Quantum-Inspired Simulated Annealing (QSA) with transverse field tunneling benchmarked live on classical CPU against Classical SA, Greedy Local Search, and Random Search.
7. **Data Sources:** Complete data provenance registry with live Open-Meteo surface observations across Indian synoptic stations (Delhi, Kolkata, Bhubaneswar, Mumbai, Chennai, Nagpur, Guwahati).
8. **Reports:** Automated incident report generator supporting downloadable RFC-4180 CSV tables and printable, publication-grade HTML/PDF summaries.
9. **Settings:** Measurement unit toggles (Metric vs Imperial), automated polling configurations, and SIH 2026 PS 26072 diagnostic metadata.

## 💻 How to Run Locally

### Prerequisites
- Node.js (v18+)
- Python (v3.10+)

```bash
# 1. Clone repository
git clone https://github.com/aradesipraneeth-creator/ATLAS-Q.git
cd ATLAS-Q

# 2. Install backend dependencies
pip install -r requirements.txt

# 3. Build React frontend production bundle
cd frontend
npm install
npm run build
cd ..

# 4. Start single-service unified platform
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```
Open your browser at **`http://localhost:8000`** to view the live platform!

## 🌐 Render Cloud Deployment (Single Public URL)

ATLAS-Q is engineered as a **single unified deployable service** on Render so that you get **ONE clean public URL** with zero CORS configurations.

1. Push your changes to GitHub:
   ```bash
   git add .
   git commit -m "feat: complete editorial transformation with 9 pages and algorithmic nowcasting"
   git push origin main
   ```
2. Log in to [Render Dashboard](https://dashboard.render.com).
3. Connect your repository `aradesipraneeth-creator/ATLAS-Q` as a **Web Service**.
4. Configure:
   - **Runtime:** `Python`
   - **Build Command:**
     ```bash
     npm --prefix frontend install && npm --prefix frontend run build && pip install -r requirements.txt
     ```
   - **Start Command:**
     ```bash
     python -m uvicorn backend.main:app --host 0.0.0.0 --port $PORT
     ```
   - **Health Check Path:** `/api/health`
5. Click **Deploy Web Service** to receive your live public URL (e.g. `https://atlas-q.onrender.com`).
